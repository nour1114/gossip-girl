# 💋 Gossip Girl

> *You know you love me. XOXO, Gossip Girl.*

A fan-made website inspired by the iconic TV series **Gossip Girl**, bringing the drama, glamour, and secrets of Manhattan's Upper East Side into a web experience.

## ✨ About the Project

This project recreates the atmosphere of *Gossip Girl* through a fan website built as a web development project. It explores front-end development, interactive web elements, and visual presentation inspired by the show's iconic aesthetic.

## 🖥️ Built With

- **HTML5** for page structure
- **CSS3** for styling and layout
- **JavaScript** for interactivity

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/nour1114/gossip-girl.git
   ```

2. Navigate to the project folder:

   ```bash
   cd gossip-girl
   ```

3. Open the main HTML file in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for a smoother development experience.

## 📂 Project Structure

The repository contains the website's HTML pages, stylesheets, JavaScript files, images, and media assets.

## 🎯 Project Goals

- Practice front-end web development.
- Build a visually engaging website inspired by a popular TV series.
- Improve skills in HTML, CSS, and JavaScript.
- Explore the relationship between design, storytelling, and user experience.
